## TopluImza — Toplu Elektronik İmza / Batch e-signature

| Dosya / File | Sistem / OS |
|---|---|
| `topluimza_<sürüm>_amd64.deb`, `_arm64.deb` | Debian, Ubuntu, Pardus |
| `topluimza-<sürüm>-win-x64.msi` | Windows 10/11 (PATH'e eklenir) |
| `topluimza-<sürüm>-osx-arm64.pkg`, `osx-x64.pkg` | macOS (imzasız; ilk açılışta sağ tık → Aç) |
| `*.tar.gz`, `*.zip` | Kurulumsuz tek dosya / portable |
| `SHA256SUMS` | Bütünlük denetimi: `sha256sum -c SHA256SUMS` |

Ayrıntılar için README'ye bakın. Bu yazılım BTK veya TÜBİTAK tarafından onaylanmış değildir.
